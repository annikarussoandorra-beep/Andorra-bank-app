# Andorra Bank Trading Platform

Комплексная full-stack платформа для симуляции трейдинга, управления инвестициями и взаимодействия с клиентами. Приложение включает в себя клиентскую часть (торговый терминал, графики, кошелек) и мощную панель управления для персонала (CRM, чаты, управление балансами, торговые боты).

## 🛠 Технологический стек
- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, Framer Motion (анимации).
- **Backend:** Node.js, Express.
- **База данных:** MongoDB (Mongoose).
- **Уведомления:** Web-Push API (Service Workers).
- **Аутентификация:** Cookie-based сессии.

## 🚀 Установка и запуск

### 1. Предварительные требования
- Установленный **Node.js** (версия 18+).
- Доступ к кластеру **MongoDB** (локально или MongoDB Atlas).

### 2. Клонирование и установка зависимостей
```bash
# Установка всех зависимостей (включая клиентские и серверные)
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корне проекта и добавьте следующие переменные:
```env
# Ключи для Push-уведомлений (можно сгенерировать через npx web-push generate-vapid-keys)
VAPID_PUBLIC_KEY=ваш_публичный_ключ
VAPID_PRIVATE_KEY=ваш_приватный_ключ
VAPID_EMAIL=mailto:support@yourdomain.com

# Строка подключения к базе данных (по умолчанию прописана в server.ts, но лучше вынести сюда)
MONGODB_URI=mongodb+srv://<user>:<password>@cluster...
```

### 4. Запуск приложения
**Режим разработки (Development):**
```bash
# Запускает Express сервер и Vite middleware на порту 3000
npm run dev
```

**Продакшн сборка (Production):**
```bash
npm run build
npm start
```

## 👥 Иерархия ролей

В системе предусмотрена строгая иерархия доступов:
1. **Admin / Master:** Полный доступ ко всей системе, всем клиентам, персоналу, настройкам и рассылкам.
2. **Team Lead (Тимлид):** Управляет назначенной ему командой менеджеров и видит всех клиентов своей команды.
3. **Manager (Менеджер):** Работает только с закрепленными за ним клиентами.
4. **Client (Клиент):** Конечный пользователь. Видит только свой терминал, баланс и чаты со своим менеджером / поддержкой.

---

## 👑 Руководство для Администратора

Администратор имеет доступ ко всем вкладкам в разделе **Management**.

### 1. Вкладка "Staff" (Персонал)
- **Создание сотрудников:** Вы можете создавать Тимлидов и Менеджеров.
- **Назначение в команды:** При создании менеджера обязательно привяжите его к определенной команде (Team), чтобы Тимлид мог его видеть.

### 2. Вкладка "Teams" (Команды)
- Создавайте отделы продаж/сопровождения.
- Назначайте Тимлида на каждую команду.
- Удаление команды автоматически отвяжет всех менеджеров от нее (они не удалятся, но останутся без команды).

### 3. Вкладка "System" (Система очистки)
- Автоматическая очистка базы данных от "мертвых" душ.
- **Unactivated Accounts:** Настройте, через сколько дней удалять клиентов, которые зарегистрировались, но так и не были активированы.
- **Activated Accounts:** Настройте, через сколько дней бездействия (с момента последнего входа) удалять активных клиентов.
- *Примечание:* Удаление клиента также стирает всю историю его транзакций, настройки ботов и переписки.

### 4. Вкладка "Notifications" (Уведомления)
- **Массовые рассылки:** Отправляйте Push-уведомления конкретным клиентам или всем неактивированным клиентам сразу (кнопка "All Clients with Inactive Accounts").
- **Отложенные пуши:** Вы можете запланировать отправку уведомления на определенную дату и время.

## 🎯 Руководство для Тимлида

Тимлид — это руководитель группы менеджеров.
- **Видимость:** Вы видите только тех менеджеров, которые привязаны к вашей команде, и всех их клиентов.
- **Контроль чатов:** В разделе чатов вы можете читать переписки ваших менеджеров с клиентами, а также видеть обращения клиентов вашей команды в службу поддержки (Support).
- **Помощь менеджерам:** Вы можете напрямую написать любому клиенту вашей команды. У клиента при этом появится новый чат с вами (как со вторым менеджером).

## 💼 Руководство для Менеджера

Менеджер — основное контактное лицо для клиента.

### 1. Управление клиентами (Вкладка Clients)
- **Активация:** Новые клиенты не могут торговать, пока вы не нажмете кнопку "Activate" в их профиле.
- **Демо-время:** Неактивированным клиентам дается демо-время. Вы можете добавлять или убавлять его.
- **Баланс и Транзакции:** Нажмите на иконку 💰 (Доллар), чтобы начислить клиенту бонус, провести депозит, списание или выдать кредит. Это мгновенно отразится на его балансе.

### 2. Торговые боты (Bot Config)
Нажмите на иконку 🤖 (Робот) в строке клиента, чтобы настроить авто-трейдинг:
- **Conservative (Консервативная):** Медленный, но стабильный рост баланса.
- **Aggressive (Агрессивная):** Быстрый рост, более крупные сделки.
- Выберите активы, которыми бот будет "торговать", и максимальную сумму инвестиции. Бот работает в фоновом режиме и автоматически генерирует плюсовые сделки для клиента.

### 3. Работа с Чатом (Chat)
У вас есть две вкладки в Чате:
- **Direct (Личные):** Прямое общение с клиентом от вашего имени.
- **Support (Поддержка):** Общение с клиентом от лица "Support Service". Клиент не знает, что ему отвечает его менеджер. Это удобно для решения "технических" вопросов.

## ✨ Ключевые фишки и функционал (Лайфхаки)

### 💳 Отправка реквизитов и ссылок на оплату
В чате (рядом со строкой ввода) есть кнопка с иконкой **Кредитной карты**.
Она позволяет отправлять красиво оформленные системные сообщения:
1. **Bank Requisites:** Отправка банковских реквизитов или крипто-кошельков. У клиента появится красивая карточка с кнопкой "Скопировать в один клик".
2. **Payment Request:** Отправка ссылки на оплату. Клиент увидит карточку с призывом к действию и кнопкой, которая переведет его на шлюз оплаты.

### ✏️ Редактирование и удаление сообщений
- Вы можете удалить любое свое сообщение (или сообщение клиента, если вы админ), нажав на иконку корзины при наведении на сообщение.
- Вы можете отредактировать свой текст (иконка карандаша). У сообщения появится пометка *edited*.

### 🧹 Очистка истории чата
Если переписка стала слишком длинной или содержит нежелательную информацию, нажмите на три точки (⋮) в правом верхнем углу чата и выберите **"Clear Chat"**. Это удалит всю историю переписки с данным клиентом.

### 🟢 Статусы "В сети"
В списке чатов и в самом чате отображается статус клиента (Online / Offline). Статус "Online" горит зеленым, если клиент совершал любые действия на платформе в течение последней минуты.

### 🔔 Звуковые уведомления
При получении нового сообщения от клиента (как в Direct, так и в Support) у менеджера прозвучит звуковой сигнал. Звук не проигрывается, если сообщение отправляете вы сами.

### 📱 Адаптивность
Платформа полностью адаптирована под мобильные устройства. На телефонах интерфейс чата работает как полноценное мобильное приложение (с кнопкой "Назад" к списку контактов), а поля ввода автоматически масштабируются для удобства печати без "прыжков" экрана на iOS.
